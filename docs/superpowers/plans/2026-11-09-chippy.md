# Chippy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone GTK4/libadwaita app, Chippy, that signs in to Xiaomi, controls the user's Dreame robot vacuum directly, shows the cloud room map with selectable rooms, sends notifications, runs in the background, and can install its own GNOME Shell top-bar extension.

**Architecture:** One Python process on the GLib main loop. A GTK-free `chippy.core` package (ported from `dreamed`, with model profiles) does robot/cloud/map/keyring work; a `VacuumController` GObject owns the robot and runs blocking calls on worker threads; the UI (map widget, sidebar, dialogs) and a Gio D-Bus export for the extension sit on top. Shipped as a Flatpak; also runs from source.

**Tech Stack:** Python 3.14 (system) + PyGObject 3.58, GTK 4.24, libadwaita 1.10; python-miio 0.5.12, micloud 0.6, secretstorage, requests; pytest, ruff; GJS for the Shell extension (GNOME 51 ESM); flatpak-builder with `org.gnome.Platform//51`.

**Spec:** `docs/superpowers/specs/2026-11-09-chippy-design.md` (read it first).

**Source to port:** `~/GitHub/dreame-vacuum-gnome` branch `feat/v1` (call it `$DV` below:
`DV=~/GitHub/dreame-vacuum-gnome`). Its code is working and live-verified; port it, don't rewrite it.

## Global Constraints

- App id `io.github.eboye.Chippy`; D-Bus interface `io.github.eboye.Chippy.Vacuum` at `/io/github/eboye/Chippy` on the app's own bus name; extension uuid `chippy@eboye.github.io`.
- Keyring item attribute `application=chippy`, label `Chippy robot vacuum`; legacy item `application=dreamed` is read and copied, never modified or deleted by the app.
- Keyring access through `secretstorage` (direct Secret Service), never libsecret's portal backend.
- Secrets never in files, logs, test fixtures or commits. Passwords never logged.
- Never start a real cleaning run without the user asking. Tests and the nested check use the fake robot only.
- The extension installer copies (never symlinks) and only deletes a target that is a real directory containing `.chippy-installed`.
- Minimum visible room area 0.25 m² (smaller rooms are hidden by default, once).
- Poll intervals: 15 s idle, 5 s while cleaning/returning, 60 s offline; offline after 3 failed polls.
- Git: repo-local identity `eboye <624357+eboye@users.noreply.github.com>` (already set); commit per task; never push.
- No heredocs in shell (write files with the editor tool). Shell is zsh: never use `status`, `path`, etc. as variable names.
- Nested-shell runs export XDG_*/DCONF_PROFILE before `dbus-run-session` (isolation; see Task 14).
- Line length 100, ruff rules `E F I UP B`; eslint for the extension (port `$DV/eslint.config.js`).

```python
"""Everything model-specific. Nothing outside this module knows a siid/piid."""

import json
from dataclasses import dataclass, replace

from .state import Snapshot


class UnsupportedModel(Exception):
    pass


@dataclass(frozen=True, eq=False)
class Profile:
    key: str
    models: tuple[str, ...]
    tested: bool
    props: dict[str, tuple[int, int]]
    actions: dict[str, tuple[int, int]]
    cleaning_statuses: frozenset[int]
    statuses: dict[int, str]
    suction: dict[int, str]
    water: dict[int, str]
    faults: dict[int, str]
    attention_faults: frozenset[int]
    map_info_prop: tuple[int, int] | None
    map_format: str  # "plain" (base64+zlib frame) or "encrypted" (not supported yet)
    segment_clean_mode: int

    def map_state(self, raw_status: int | None, charging: int | None) -> str:
        if raw_status in self.cleaning_statuses:
            return "cleaning"
        if raw_status in self.statuses:
            return self.statuses[raw_status]
        return "charging" if charging == 1 else "idle"

    def fault_text(self, code: int) -> str:
        if not code:
            return ""
        return self.faults.get(code, f"Fault {code}")

    def parse_properties(self, results: list[dict]) -> Snapshot:
        lookup = {ids: key for key, ids in self.props.items()}
        values: dict[str, object] = {}
        for item in results:
            if item.get("code", 0) != 0:
                continue
            key = lookup.get((item.get("siid"), item.get("piid")))
            if key is not None:
                values[key] = item.get("value")
        fault = int(values.get("fault") or 0)
        return Snapshot(
            state=self.map_state(values.get("status"), values.get("charging")),
            battery=int(values.get("battery") or 0),
            charging=values.get("charging") == 1,
            fault=fault,
            error=self.fault_text(fault),
            suction=self.suction.get(values.get("suction"), ""),
            water=self.water.get(values.get("water"), ""),
            has_water_tank=values.get("water_tank") == 1,
            cleaned_area=int(values.get("cleaned_area") or 0),
            cleaning_time=int(values.get("cleaning_time") or 0),
        )

    def room_clean_params(self, ids: list[int], suction: str, water: str) -> list[dict]:
        from .state import name_to_value

        s_val = name_to_value(self.suction, suction)
        w_val = name_to_value(self.water, water)
        selects = [[int(seg), 1, s_val, w_val, order] for order, seg in enumerate(ids, start=1)]
        payload = json.dumps({"selects": selects}, separators=(",", ":"))
        return [{"piid": 1, "value": self.segment_clean_mode}, {"piid": 10, "value": payload}]


# dreame.vacuum.r2209 (urn:miot-spec-v2:device:vacuum:0000A006:dreame-r2209:2), live-verified.
R2209 = Profile(
    key="r2209",
    models=("dreame.vacuum.r2209",),
    tested=True,
    props={
        "status": (2, 1), "fault": (2, 2), "battery": (3, 1), "charging": (3, 2),
        "cleaning_time": (4, 2), "cleaned_area": (4, 3), "suction": (4, 4), "water": (4, 5),
        "water_tank": (4, 6),
    },
    actions={
        "start": (2, 1), "pause": (2, 2), "stop": (4, 2), "dock": (3, 1), "locate": (7, 1),
        "clean": (4, 1), "map_request": (6, 1),
    },
    cleaning_statuses=frozenset({1, 7, 11, 12}),
    statuses={3: "paused", 4: "error", 5: "returning", 6: "charging", 13: "docked"},
    suction={0: "quiet", 1: "standard", 2: "strong", 3: "turbo"},
    water={1: "low", 2: "medium", 3: "high"},
    faults={
        1: "Wheel lifted", 2: "Cliff sensor error", 3: "Bumper stuck", 8: "Dust bin missing",
        9: "Water tank missing", 10: "Water tank empty", 11: "Dust bin full",
        12: "Main brush tangled", 13: "Side brush tangled", 14: "Fan error",
        15: "Left wheel error", 16: "Right wheel error", 19: "Cannot find the dock",
        20: "Battery low", 47: "Robot is blocked",
    },
    attention_faults=frozenset({8, 9, 10, 11}),
    map_info_prop=(6, 8),
    map_format="plain",
    segment_clean_mode=18,
)

PROFILES: tuple[Profile, ...] = (R2209,)
_DREAME = "dreame.vacuum."


def is_supported(model: str) -> bool:
    return model.startswith(_DREAME)


def profile_for(model: str) -> Profile:
    for profile in PROFILES:
        if model in profile.models:
            return profile
    if is_supported(model):
        # Untested Dreame model: most share the r2209's MIoT layout.
        return replace(R2209, key=f"{R2209.key}-generic", models=(model,), tested=False)
    raise UnsupportedModel(model)
```

```python
"""Robot token and Xiaomi login, kept in GNOME Keyring only."""

import json
from dataclasses import asdict, dataclass, field, fields

ATTRS = {"application": "chippy"}
LEGACY_ATTRS = {"application": "dreamed"}
LABEL = "Chippy robot vacuum"


@dataclass
class Credentials:
    ip: str
    token: str
    did: str
    model: str
    country: str
    username: str = ""
    password: str = ""
    # Xiaomi session (user_id, service_token, ssecurity) reused so map downloads don't need a
    # fresh password login, which Xiaomi answers with email 2FA.
    cloud_session: dict = field(default_factory=dict)


class KeyringLocked(Exception):
    """The login keyring is locked and the unlock prompt was dismissed."""


def default_collection():
    import secretstorage

    conn = secretstorage.dbus_init()
    collection = secretstorage.get_default_collection(conn)
    # secretstorage's unlock() returns True when the user dismissed the prompt.
    if collection.is_locked() and collection.unlock():
        raise KeyringLocked("the GNOME keyring is locked (unlock prompt dismissed)")
    return collection


def _parse(secret: bytes) -> Credentials:
    data = json.loads(secret)
    known = {f.name for f in fields(Credentials)}
    return Credentials(**{k: v for k, v in data.items() if k in known})


def save(creds: Credentials, collection) -> None:
    secret = json.dumps(asdict(creds)).encode()
    collection.create_item(LABEL, dict(ATTRS), secret, replace=True)


def load(collection, *, import_legacy: bool = True) -> Credentials | None:
    for item in collection.search_items(dict(ATTRS)):
        return _parse(item.get_secret())
    if import_legacy:
        for item in collection.search_items(dict(LEGACY_ATTRS)):
            creds = _parse(item.get_secret())
            save(creds, collection)
            return creds
    return None


def delete(collection) -> None:
    for item in list(collection.search_items(dict(ATTRS))):
        item.delete()


class _MemoryItem:
    def __init__(self, owner, label, attributes, secret):
        self._owner, self.label, self.attributes, self._secret = owner, label, attributes, secret

    def get_secret(self) -> bytes:
        return self._secret

    def delete(self) -> None:
        self._owner.items.remove(self)


class MemoryCollection:
    """In-memory stand-in for a Secret Service collection (tests and --fake)."""

    def __init__(self):
        self.items: list[_MemoryItem] = []

    def search_items(self, attributes):
        return [i for i in self.items if all(i.attributes.get(k) == v
                                             for k, v in attributes.items())]

    def create_item(self, label, attributes, secret, replace=True):
        if replace:
            for item in self.search_items(attributes):
                if item.attributes == attributes:
                    self.items.remove(item)
        item = _MemoryItem(self, label, dict(attributes), bytes(secret))
        self.items.append(item)
        return item
```

```python
"""Find the vacuums on a Xiaomi account."""

import logging
from dataclasses import dataclass

from .cloud import COUNTRIES
from .credentials import Credentials
from .profiles import is_supported, profile_for

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class FoundVacuum:
    country: str
    did: str
    model: str
    name: str
    ip: str
    token: str
    supported: bool
    tested: bool


def discover_vacuums(cloud, countries=COUNTRIES) -> list[FoundVacuum]:
    found: list[FoundVacuum] = []
    for country in countries:
        try:
            devices = cloud.get_devices(country=country) or []
        except Exception as err:  # noqa: BLE001 - one bad region must not hide the others
            log.warning("device list for %s failed: %s", country, err)
            continue
        for d in devices:
            model = str(d.get("model", ""))
            if ".vacuum." not in model:
                continue
            supported = is_supported(model)
            found.append(FoundVacuum(
                country=country, did=str(d.get("did", "")), model=model,
                name=str(d.get("name") or model), ip=str(d.get("localip") or ""),
                token=str(d.get("token") or ""), supported=supported,
                tested=supported and profile_for(model).tested,
            ))
    return sorted(found, key=lambda v: (not v.supported, not v.tested, v.name))


def credentials_for(v: FoundVacuum, username: str, password: str, session: dict) -> Credentials:
    return Credentials(ip=v.ip, token=v.token, did=v.did, model=v.model, country=v.country,
                       username=username, password=password, cloud_session=dict(session))
```

```python
"""Non-secret local data: room names/hidden rooms, settings, cached map."""

import json
import os
from dataclasses import asdict, dataclass, field, fields
from pathlib import Path


def _xdg(var: str, fallback: str) -> Path:
    return Path(os.environ.get(var) or Path.home() / fallback)


def config_dir() -> Path:
    return _xdg("XDG_CONFIG_HOME", ".config") / "chippy"


def cache_dir() -> Path:
    return _xdg("XDG_CACHE_HOME", ".cache") / "chippy"


def legacy_names_path() -> Path:
    # The host path, not XDG_CONFIG_HOME: inside Flatpak that points into ~/.var/app.
    return Path.home() / ".config" / "dreamed" / "room-names.json"


def _write_atomic(path: Path, data: bytes) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(f".{path.name}.tmp")
    tmp.write_bytes(data)
    os.replace(tmp, path)


def _read_json(path: Path) -> dict:
    try:
        data = json.loads(path.read_text())
    except (OSError, ValueError):
        return {}
    return data if isinstance(data, dict) else {}


def _int_names(data: object) -> dict[int, str]:
    if not isinstance(data, dict):
        return {}
    return {int(k): v.strip() for k, v in data.items()
            if isinstance(k, str) and k.isascii() and k.isdigit() and isinstance(v, str)
            and v.strip()}


class RoomStore:
    def __init__(self, path: Path | None = None, legacy: Path | None = None):
        self._path = path or config_dir() / "rooms.json"
        data = _read_json(self._path)
        self.names: dict[int, str] = _int_names(data.get("names"))
        hidden = data.get("hidden")
        self.hidden: set[int] = {int(i) for i in hidden if isinstance(i, int)} \
            if isinstance(hidden, list) else set()
        self._seeded = data.get("seeded") is True
        self._imported = data.get("imported") is True
        if not self._imported:
            self.names = {**_int_names(_read_json(legacy or legacy_names_path())), **self.names}
            self._imported = True
            self._save()

    def rename(self, seg_id: int, name: str) -> None:
        if name.strip():
            self.names[seg_id] = name.strip()
        else:
            self.names.pop(seg_id, None)
        self._save()

    def set_hidden(self, seg_id: int, hidden: bool) -> None:
        (self.hidden.add if hidden else self.hidden.discard)(seg_id)
        self._save()

    def seed_hidden(self, ids: set[int]) -> bool:
        if self._seeded:
            return False
        self.hidden |= set(ids)
        self._seeded = True
        self._save()
        return True

    def clear(self) -> None:
        self.names, self.hidden, self._seeded = {}, set(), False
        self._save()

    def _save(self) -> None:
        doc = {"names": {str(k): v for k, v in sorted(self.names.items())},
               "hidden": sorted(self.hidden), "seeded": self._seeded,
               "imported": self._imported}
        _write_atomic(self._path, json.dumps(doc, indent=2).encode())


@dataclass
class Settings:
    background: bool = True
    autostart: bool = True
    top_bar: bool = False
    signed_out: bool = False  # user signed out: don't re-import the dreamed keyring item
    path: Path = field(default=Path(), repr=False, compare=False)

    @classmethod
    def load(cls, path: Path | None = None) -> "Settings":
        path = path or config_dir() / "settings.json"
        data = _read_json(path)
        values = {f.name: data[f.name] for f in fields(cls)
                  if f.name != "path" and isinstance(data.get(f.name), bool)}
        return cls(**values, path=path)

    def save(self) -> None:
        doc = {k: v for k, v in asdict(self).items() if k != "path"}
        _write_atomic(self.path, json.dumps(doc, indent=2).encode())


class MapCache:
    def __init__(self, path: Path | None = None):
        self._path = path or cache_dir() / "map.payload"

    def load(self) -> bytes | None:
        try:
            return self._path.read_bytes()
        except OSError:
            return None

    def save(self, payload: bytes) -> None:
        _write_atomic(self._path, payload)

    def clear(self) -> None:
        self._path.unlink(missing_ok=True)
```

```python
"""Pure map geometry: display grid, rooms, label anchors, zoom/pan, texture pixels."""

from collections import deque
from dataclasses import dataclass

from .core.mapdecode import MapFrame

MIN_VISIBLE_AREA = 0.25
PALETTE = ["#5bc8af", "#f6d32d", "#cdab8f", "#99c1f1", "#ffa348", "#62a0ea", "#57e389",
           "#f66151", "#dc8add", "#e5a50a", "#8ff0a4", "#c061cb"]
_STEPS = ((1, 0), (-1, 0), (0, 1), (0, -1))


@dataclass(frozen=True)
class MapGrid:
    width: int
    height: int
    grid_mm: int
    cells: bytes
    charger: tuple[float, float] | None

    def seg_at(self, col: int, row: int) -> int:
        if 0 <= col < self.width and 0 <= row < self.height:
            return self.cells[row * self.width + col]
        return 0

    def cell_area(self) -> float:
        return (self.grid_mm / 1000) ** 2


def grid_from_frame(frame: MapFrame) -> MapGrid:
    w, h = frame.width, frame.height
    rows = [frame.pixels[r * w:(r + 1) * w] for r in range(h)]
    cells = bytes(p & 0x3F for row in reversed(rows) for p in row)
    charger = None
    if frame.charger:
        cx = (frame.charger[0] - frame.left) / frame.grid_mm
        cy = h - (frame.charger[1] - frame.top) / frame.grid_mm
        charger = (cx, cy)
    return MapGrid(w, h, frame.grid_mm, cells, charger)


def room_areas(grid: MapGrid) -> dict[int, int]:
    counts: dict[int, int] = {}
    for seg in grid.cells:
        if seg:
            counts[seg] = counts.get(seg, 0) + 1
    return counts


def tiny_rooms(grid: MapGrid) -> set[int]:
    area = grid.cell_area()
    return {seg for seg, n in room_areas(grid).items() if n * area < MIN_VISIBLE_AREA}


def label_anchors(grid: MapGrid) -> dict[int, tuple[float, float]]:
    """Per room, the centre of the cell farthest from the room's edge (inside U shapes too)."""
    w, h = grid.width, grid.height
    dist = [-1] * (w * h)
    queue: deque[tuple[int, int]] = deque()
    for row in range(h):
        for col in range(w):
            seg = grid.seg_at(col, row)
            if not seg or any(grid.seg_at(col + dx, row + dy) != seg for dx, dy in _STEPS):
                dist[row * w + col] = 0
                queue.append((col, row))
    while queue:
        col, row = queue.popleft()
        for dx, dy in _STEPS:
            nc, nr = col + dx, row + dy
            if 0 <= nc < w and 0 <= nr < h and dist[nr * w + nc] < 0:
                dist[nr * w + nc] = dist[row * w + col] + 1
                queue.append((nc, nr))
    best: dict[int, tuple[int, int, int]] = {}
    for row in range(h):
        for col in range(w):
            seg = grid.seg_at(col, row)
            d = dist[row * w + col]
            if seg and (seg not in best or d > best[seg][0]):
                best[seg] = (d, col, row)
    return {seg: (col + 0.5, row + 0.5) for seg, (_, col, row) in best.items()}


@dataclass(frozen=True)
class Room:
    id: int
    name: str
    area_m2: float | None
    color: str
    anchor: tuple[float, float] | None
    hidden: bool


def build_rooms(grid: MapGrid | None, cloud_names: dict[int, str],
                user_names: dict[int, str], hidden: set[int]) -> list[Room]:
    counts = room_areas(grid) if grid else {}
    anchors = label_anchors(grid) if grid else {}
    ids = sorted(set(counts) | set(cloud_names) | set(user_names))
    rooms = []
    for index, seg in enumerate(ids):
        name = user_names.get(seg) or cloud_names.get(seg) or f"Room {seg}"
        area = round(counts[seg] * grid.cell_area(), 1) if grid and seg in counts else None
        rooms.append(Room(seg, name, area, PALETTE[index % len(PALETTE)],
                          anchors.get(seg), seg in hidden))
    return rooms


class Viewport:
    MARGIN = 0.92

    def __init__(self, map_w: int, map_h: int):
        self.map_w, self.map_h = map_w, map_h
        self.width = self.height = 1.0
        self.scale, self.ox, self.oy, self.fitted = 1.0, 0.0, 0.0, True

    def fit_scale(self) -> float:
        return min(self.width / self.map_w, self.height / self.map_h) * self.MARGIN

    def fit(self) -> None:
        self.scale = self.fit_scale()
        self.ox = (self.width - self.map_w * self.scale) / 2
        self.oy = (self.height - self.map_h * self.scale) / 2
        self.fitted = True

    def resize(self, width: float, height: float) -> None:
        self.width, self.height = max(width, 1.0), max(height, 1.0)
        if self.fitted:
            self.fit()

    def zoom_at(self, factor: float, px: float, py: float) -> None:
        cx, cy = self.to_cell(px, py)
        fit = self.fit_scale()
        self.scale = min(max(self.scale * factor, fit * 0.5), fit * 8)
        self.ox, self.oy = px - cx * self.scale, py - cy * self.scale
        self.fitted = False

    def pan(self, dx: float, dy: float) -> None:
        self.ox += dx
        self.oy += dy
        self.fitted = False

    def to_cell(self, px: float, py: float) -> tuple[float, float]:
        return (px - self.ox) / self.scale, (py - self.oy) / self.scale

    def to_widget(self, cx: float, cy: float) -> tuple[float, float]:
        return self.ox + cx * self.scale, self.oy + cy * self.scale


def _rgb(hex_color: str) -> tuple[int, int, int]:
    return tuple(int(hex_color[i:i + 2], 16) for i in (1, 3, 5))  # type: ignore[return-value]


def _mix(a: tuple[int, int, int], b: tuple[int, int, int], t: float) -> tuple[int, int, int]:
    return tuple(int(x * t + y * (1 - t)) for x, y in zip(a, b, strict=True))  # type: ignore


def texture_rgba(grid: MapGrid, rooms: list[Room], selected: set[int],
                 background: tuple[int, int, int]) -> bytes:
    colours: dict[int, tuple[int, int, int]] = {}
    for room in rooms:
        base = _rgb(room.color)
        if room.hidden:
            base = _mix((128, 128, 128), background, 0.45)
        elif room.id not in selected:
            base = _mix(base, background, 0.55)
        colours[room.id] = base
    out = bytearray(grid.width * grid.height * 4)
    for row in range(grid.height):
        for col in range(grid.width):
            seg = grid.seg_at(col, row)
            if not seg:
                continue
            r, g, b = colours.get(seg, (128, 128, 128))
            if any(grid.seg_at(col + dx, row + dy) != seg for dx, dy in _STEPS):
                r, g, b = _mix((r, g, b), background, 0.7)  # outline between rooms
            i = (row * grid.width + col) * 4
            out[i:i + 4] = bytes((r, g, b, 255))
    return bytes(out)
```

```python
class InlineRunner:
    def run(self, func, callback):
        try:
            result, error = func(), None
        except Exception as err:  # noqa: BLE001
            result, error = None, err
        callback(result, error)

    def shutdown(self):
        pass


class ManualScheduler:
    def __init__(self):
        self.pending = []

    def call_later(self, seconds, fn):
        self.pending.append((seconds, fn))
        return len(self.pending)

    def cancel(self, handle):
        self.pending[handle - 1] = (None, None)

    def fire(self):
        seconds, fn = next(p for p in reversed(self.pending) if p[1])
        self.pending = []
        fn()
        return seconds
```

```python
"""The one owner of the robot: polling, actions, map refresh, notifications."""

import logging
import time
from collections.abc import Callable
from concurrent.futures import ThreadPoolExecutor
from dataclasses import replace

from gi.repository import GLib, GObject

from .core.mapdecode import decode_map
from .core.notify import Notifier
from .core.state import Snapshot
from .mapmodel import build_rooms, grid_from_frame, tiny_rooms

log = logging.getLogger(__name__)

OFFLINE_AFTER = 3
OFFLINE_ERROR = "Can't reach the robot (Wi-Fi asleep, wrong IP, or the token changed)"
ENCRYPTED_MAP = "This model's map can't be shown yet"
_ACTIVE = {"cleaning", "returning"}


def next_interval(state: str, failures: int) -> int:
    if failures >= OFFLINE_AFTER:
        return 60
    return 5 if state in _ACTIVE else 15


class ThreadRunner:
    """Run blocking calls off the main loop; deliver (result, error) back on it."""

    def __init__(self):
        self._pool = ThreadPoolExecutor(max_workers=2, thread_name_prefix="chippy")

    def run(self, func, callback) -> None:
        def done(future):
            error = future.exception()
            result = None if error else future.result()

            def deliver():
                callback(result, error)
                return GLib.SOURCE_REMOVE

            GLib.idle_add(deliver)

        self._pool.submit(func).add_done_callback(done)

    def shutdown(self) -> None:
        self._pool.shutdown(wait=False, cancel_futures=True)


class GLibScheduler:
    def call_later(self, seconds: float, fn) -> int:
        def fire():
            fn()
            return GLib.SOURCE_REMOVE

        return GLib.timeout_add(int(seconds * 1000), fire)

    def cancel(self, handle: int) -> None:
        GLib.source_remove(handle)


class VacuumController(GObject.Object):
    __gsignals__ = {
        "snapshot-changed": (GObject.SignalFlags.RUN_FIRST, None, ()),
        "rooms-changed": (GObject.SignalFlags.RUN_FIRST, None, ()),
        "map-changed": (GObject.SignalFlags.RUN_FIRST, None, ()),
        "action-failed": (GObject.SignalFlags.RUN_FIRST, None, (str,)),
        "map-failed": (GObject.SignalFlags.RUN_FIRST, None, (str,)),
        "notify-user": (GObject.SignalFlags.RUN_FIRST, None, (str, str)),
    }

    def __init__(self, vacuum, profile, rooms, map_cache,
                 fetch_map_payload: Callable[[], bytes], runner=None, scheduler=None,
                 clock=time.monotonic):
        super().__init__()
        self._vacuum, self.profile = vacuum, profile
        self._room_store, self._map_cache, self._fetch = rooms, map_cache, fetch_map_payload
        self._runner = runner or ThreadRunner()
        self._scheduler = scheduler or GLibScheduler()
        self._clock = clock
        self._notifier = Notifier(profile.attention_faults)
        self.snapshot = Snapshot()
        self.failures = 0
        self.grid = None
        self.cloud_names: dict[int, str] = {}
        self.rooms = []
        self._timer: int | None = None
        self._running = False
        self._in_flight = False
        self._poke_pending = False

    # lifecycle -------------------------------------------------------------
    def start(self) -> None:
        cached = self._map_cache.load()
        if cached:
            try:
                self._set_frame(decode_map(cached))
            except Exception as err:  # noqa: BLE001 - a bad cache is just ignored
                log.warning("cached map unreadable: %s", err)
        self._rebuild_rooms()
        self._running = True
        self._poll_now()
        self.refresh_map()

    def stop(self) -> None:
        self._running = False
        if self._timer is not None:
            self._scheduler.cancel(self._timer)
            self._timer = None
        self._runner.shutdown()

    # polling ---------------------------------------------------------------
    def poke(self) -> None:
        if not self._running:
            return
        if self._timer is not None:
            self._scheduler.cancel(self._timer)
            self._timer = None
        self._poll_now()

    def _poll_now(self) -> None:
        if self._in_flight:
            self._poke_pending = True
            return
        self._in_flight = True
        self._runner.run(self._vacuum.poll, self._on_poll)

    def _on_poll(self, snap, error) -> None:
        self._in_flight = False
        if error is not None:
            self.failures += 1
            log.warning("poll failed (%d): %s", self.failures, error)
            if self.failures < OFFLINE_AFTER:
                self._schedule()
                return
            snap = replace(self.snapshot, state="offline", error=OFFLINE_ERROR)
        else:
            self.failures = 0
        prev, self.snapshot = self.snapshot, snap
        if prev != snap:
            self.emit("snapshot-changed")
        if prev != snap or snap.state == "offline":
            for title, body in self._notifier.events(prev, snap, self._clock()):
                self.emit("notify-user", title, body)
        self._schedule()

    def _schedule(self) -> None:
        if not self._running:
            return
        if self._poke_pending:
            self._poke_pending = False
            self._poll_now()
            return
        self._timer = self._scheduler.call_later(
            next_interval(self.snapshot.state, self.failures), self._tick)

    def _tick(self) -> None:
        self._timer = None
        self._poll_now()

    # actions ---------------------------------------------------------------
    def act(self, name: str, *args, on_done=None) -> None:
        method = getattr(self._vacuum, name)

        def done(_result, error):
            if error is not None:
                label = name.replace("_", " ").capitalize()
                self.emit("action-failed", f"{label} failed: {error}")
            if on_done is not None:
                on_done(error)
            self.poke()

        self._runner.run(lambda: method(*args), done)

    def clean_rooms(self, ids, on_done=None) -> None:
        self.act("clean_rooms", list(ids), self.snapshot.suction or "standard",
                 self.snapshot.water or "medium", on_done=on_done)

    # map and rooms ---------------------------------------------------------
    def refresh_map(self) -> None:
        if self.profile.map_format != "plain":
            self.emit("map-failed", ENCRYPTED_MAP)
            return

        def work():
            payload = self._fetch()
            return payload, decode_map(payload)

        self._runner.run(work, self._on_map)

    def _on_map(self, result, error) -> None:
        if error is not None:
            log.warning("map refresh failed: %s", error)
            self.emit("map-failed", str(error))
            return
        payload, frame = result
        self._map_cache.save(payload)
        self._set_frame(frame)

    def _set_frame(self, frame) -> None:
        self.grid = grid_from_frame(frame)
        self.cloud_names = dict(frame.names)
        self._room_store.seed_hidden(tiny_rooms(self.grid))
        self._rebuild_rooms(force=True)
        self.emit("map-changed")

    def _rebuild_rooms(self, force: bool = False) -> None:
        rooms = build_rooms(self.grid, self.cloud_names, self._room_store.names,
                            self._room_store.hidden)
        if force or rooms != self.rooms:
            self.rooms = rooms
            self.emit("rooms-changed")

    def visible_rooms(self):
        return [r for r in self.rooms if not r.hidden]

    def rename_room(self, seg_id: int, name: str) -> None:
        self._room_store.rename(seg_id, name)
        self._rebuild_rooms()

    def set_room_hidden(self, seg_id: int, hidden: bool) -> None:
        self._room_store.set_hidden(seg_id, hidden)
        self._rebuild_rooms()
```

```python
    <method name="ShowWindow"/>
  </interface>
</node>"""

_SNAPSHOT_PROPS = {
    "State": ("state", "s"), "Battery": ("battery", "y"), "Charging": ("charging", "b"),
    "Error": ("error", "s"), "Suction": ("suction", "s"), "Water": ("water", "s"),
    "HasWaterTank": ("has_water_tank", "b"), "CleanedArea": ("cleaned_area", "u"),
    "CleaningTime": ("cleaning_time", "u"),
}
_ACTIONS = {"Start": "start", "Pause": "pause", "Stop": "stop", "Dock": "dock",
            "Locate": "locate", "SetSuction": "set_suction", "SetWater": "set_water"}
_FAILED = "org.freedesktop.DBus.Error.Failed"


class VacuumDBus:
    def __init__(self, show_window: Callable[[], None]):
        self._show_window = show_window
        self._controller = None
        self._signal_ids: list[int] = []
        self._connection: Gio.DBusConnection | None = None
        self._path = OBJECT_PATH
        self._reg_id = 0
        self._last: dict[str, GLib.Variant] = {}

    def register(self, connection: Gio.DBusConnection, path: str) -> None:
        info = Gio.DBusNodeInfo.new_for_xml(XML).interfaces[0]
        self._connection, self._path = connection, path
        self._reg_id = connection.register_object(path, info, self._on_call, self._on_get, None)
        self._last = self._values()

    def unregister(self) -> None:
        if self._connection and self._reg_id:
            self._connection.unregister_object(self._reg_id)
        self._reg_id = 0
        self.attach(None)

    def attach(self, controller) -> None:
        if self._controller is not None:
            for sig in self._signal_ids:
                self._controller.disconnect(sig)
        self._signal_ids = []
        self._controller = controller
        if controller is not None:
            self._signal_ids = [controller.connect(s, lambda *_a: self._emit_changes())
                                for s in ("snapshot-changed", "rooms-changed")]
        self._emit_changes()

    # values ----------------------------------------------------------------
    def _values(self) -> dict[str, GLib.Variant]:
        snap = self._controller.snapshot if self._controller else Snapshot()
        values = {name: GLib.Variant(sig, getattr(snap, field))
                  for name, (field, sig) in _SNAPSHOT_PROPS.items()}
        rooms = self._controller.visible_rooms() if self._controller else []
        values["Rooms"] = GLib.Variant("a(us)", [(r.id, r.name) for r in rooms])
        return values

    def _emit_changes(self) -> None:
        if not (self._connection and self._reg_id):
            return
        values = self._values()
        changed = {k: v for k, v in values.items() if self._last.get(k) != v}
        self._last = values
        if changed:
            self._connection.emit_signal(
                None, self._path, "org.freedesktop.DBus.Properties", "PropertiesChanged",
                GLib.Variant("(sa{sv}as)", (INTERFACE, changed, [])))

    def _on_get(self, _conn, _sender, _path, _iface, prop):
        return self._values().get(prop)

    # methods ---------------------------------------------------------------
    def _on_call(self, _conn, _sender, _path, _iface, method, params, invocation):
        args = params.unpack() if params is not None else ()
        if method == "ShowWindow":
            self._show_window()
            invocation.return_value(None)
            return
        ctl = self._controller
        if ctl is None:
            invocation.return_dbus_error(_FAILED, "Not signed in")
            return

        def done(error):
            if error is None:
                invocation.return_value(None)
            else:
                invocation.return_dbus_error(_FAILED, str(error))

        if method == "RefreshRooms":
            ctl.refresh_map()
            invocation.return_value(None)
        elif method == "CleanRooms":
            ctl.clean_rooms(list(args[0]), on_done=done)
        elif method in _ACTIONS:
            ctl.act(_ACTIONS[method], *args, on_done=done)
        else:
            invocation.return_dbus_error("org.freedesktop.DBus.Error.UnknownMethod", method)
```

```python
    try:
        return int(json.loads((folder / "metadata.json").read_text()).get("version", 0))
    except (OSError, ValueError, TypeError):
        return 0


class ShellExtensions:
    """org.gnome.Shell.Extensions over the session bus."""

    def __init__(self):
        self._proxy = Gio.DBusProxy.new_for_bus_sync(
            Gio.BusType.SESSION, Gio.DBusProxyFlags.DO_NOT_LOAD_PROPERTIES, None,
            "org.gnome.Shell.Extensions", "/org/gnome/Shell/Extensions",
            "org.gnome.Shell.Extensions", None)

    def _call(self, method: str, uuid: str):
        return self._proxy.call_sync(method, GLib.Variant("(s)", (uuid,)),
                                     Gio.DBusCallFlags.NONE, 5000, None).unpack()[0]

    def enable(self, uuid: str) -> bool:
        return bool(self._call("EnableExtension", uuid))

    def disable(self, uuid: str) -> bool:
        return bool(self._call("DisableExtension", uuid))

    def known(self, uuid: str) -> bool:
        return bool(self._call("GetExtensionInfo", uuid))


class Installer:
    def __init__(self, source: Path, root: Path, shell):
        self._source, self._root, self._shell = Path(source), Path(root), shell
        self.target = self._root / UUID

    def installed(self) -> bool:
        return (self.target.is_dir() and not self.target.is_symlink()
                and (self.target / MARKER).exists())

    def _check_ours(self) -> None:
        if self.target.is_symlink():
            raise ShellExtError(f"{self.target} is a symlink; Chippy won't touch it")
        if self.target.exists() and not (self.target / MARKER).exists():
            raise ShellExtError(f"{self.target} wasn't installed by Chippy; not touching it")

    def install(self) -> bool:
        self._check_ours()
        self._root.mkdir(parents=True, exist_ok=True)
        staging = self._root / f".{UUID}.chippy-tmp"
        if staging.is_symlink():
            staging.unlink()
        elif staging.exists():
            shutil.rmtree(staging)
        shutil.copytree(self._source, staging, symlinks=False)
        (staging / MARKER).write_text("Installed by Chippy; removed when you turn off "
                                      "'Show in top bar'.\n")
        if self.target.exists():
            shutil.rmtree(self.target)
        staging.rename(self.target)
        try:
            relogin = not self._shell.known(UUID)
            self._shell.enable(UUID)
        except GLib.Error:
            relogin = True
        return relogin

    def update_if_needed(self) -> bool:
        if self.installed() and _version(self._source) > _version(self.target):
            self.install()
            return True
        return False

    def remove(self) -> None:
        try:
            self._shell.disable(UUID)
        except GLib.Error:
            pass
        if not self.target.exists() and not self.target.is_symlink():
            return
        self._check_ours()
        shutil.rmtree(self.target)
```

```python
    if in_flatpak():

        return
    path = autostart_path()

        path.unlink(missing_ok=True)

    path.write_text("[Desktop Entry]\nType=Application\nName=Chippy\n"
                    f"Exec={_command()} --background\nIcon={APP_ID}\n"
                    "X-GNOME-Autostart-enabled=true\nNoDisplay=true\n")

    try:
        proxy = Gio.DBusProxy.new_for_bus_sync(
            Gio.BusType.SESSION, Gio.DBusProxyFlags.NONE, None,
            "org.freedesktop.portal.Desktop", "/org/freedesktop/portal/desktop",

            "reason": GLib.Variant("s", reason),
            "autostart": GLib.Variant("b", enabled),
            "commandline": GLib.Variant("as", ["chippy", "--background"]),
            "dbus-activatable": GLib.Variant("b", False),
        }
```

```python
"""The room map: rooms texture, labels, charger; click to select, scroll/pinch/drag."""

from gi.repository import Adw, Gdk, GLib, GObject, Graphene, Gsk, Gtk, Pango

from ..mapmodel import Viewport, texture_rgba

_DARK_BG, _LIGHT_BG = (29, 29, 32), (255, 255, 255)


def _rgba(spec: str) -> Gdk.RGBA:
    color = Gdk.RGBA()
    color.parse(spec)
    return color


class MapView(Gtk.Widget):
    __gtype_name__ = "ChippyMapView"
    __gsignals__ = {"room-clicked": (GObject.SignalFlags.RUN_FIRST, None, (int,))}

    def __init__(self):
        super().__init__(hexpand=True, vexpand=True, overflow=Gtk.Overflow.HIDDEN)
        self.grid = None
        self.rooms = []
        self.selected: set[int] = set()
        self.viewport: Viewport | None = None
        self._texture = None
        self._pointer = (0.0, 0.0)
        self._drag_origin = (0.0, 0.0)
        self._zoom_origin = 1.0

        click = Gtk.GestureClick()
        click.connect("released", self._on_click)
        self.add_controller(click)
        motion = Gtk.EventControllerMotion()
        motion.connect("motion", lambda _c, x, y: setattr(self, "_pointer", (x, y)))
        self.add_controller(motion)
        scroll = Gtk.EventControllerScroll.new(Gtk.EventControllerScrollFlags.VERTICAL)
        scroll.connect("scroll", self._on_scroll)
        self.add_controller(scroll)
        drag = Gtk.GestureDrag()
        drag.connect("drag-begin", self._on_drag_begin)
        drag.connect("drag-update", self._on_drag_update)
        self.add_controller(drag)
        zoom = Gtk.GestureZoom()
        zoom.connect("begin", lambda *_a: setattr(self, "_zoom_origin", 1.0))
        zoom.connect("scale-changed", self._on_pinch)
        self.add_controller(zoom)
        Adw.StyleManager.get_default().connect("notify::dark", lambda *_a: self._invalidate())
        Adw.StyleManager.get_default().connect("notify::accent-color",
                                               lambda *_a: self.queue_draw())

    # data ------------------------------------------------------------------
    def set_map(self, grid, rooms) -> None:
        size_changed = (grid is None or self.grid is None
                        or (grid.width, grid.height) != (self.grid.width, self.grid.height))
        self.grid, self.rooms = grid, list(rooms)
        if grid is not None and size_changed:
            self.viewport = Viewport(grid.width, grid.height)
            self.viewport.resize(self.get_width(), self.get_height())
        if grid is None:
            self.viewport = None
        self._invalidate()

    def set_rooms(self, rooms) -> None:
        self.rooms = list(rooms)
        self._invalidate()

    def set_selection(self, selected: set[int]) -> None:
        self.selected = set(selected)
        self._invalidate()

    def reset_view(self) -> None:
        if self.viewport:
            self.viewport.fit()
            self.queue_draw()

    def room_at(self, x: float, y: float) -> int:
        if not (self.grid and self.viewport):
            return 0
        cx, cy = self.viewport.to_cell(x, y)
        seg = self.grid.seg_at(int(cx // 1), int(cy // 1))
        room = next((r for r in self.rooms if r.id == seg), None)
        return seg if room and not room.hidden else 0

    def label_points(self) -> dict[int, tuple[float, float]]:
        if not self.viewport:
            return {}
        return {r.id: self.viewport.to_widget(*r.anchor) for r in self.rooms
                if r.anchor and not r.hidden}

    def _invalidate(self) -> None:
        self._texture = None
        self.queue_draw()

    # input -----------------------------------------------------------------
    def _on_click(self, gesture, n_press, x, y) -> None:
        if n_press == 2:
            self.reset_view()
            return
        seg = self.room_at(x, y)
        if seg:
            self.emit("room-clicked", seg)

    def _on_scroll(self, _ctl, _dx, dy) -> bool:
        if not self.viewport:
            return False
        self.viewport.zoom_at(1 / 1.15 if dy > 0 else 1.15, *self._pointer)
        self.queue_draw()
        return True

    def _on_drag_begin(self, _gesture, _x, _y) -> None:
        if self.viewport:
            self._drag_origin = (self.viewport.ox, self.viewport.oy)

    def _on_drag_update(self, _gesture, dx, dy) -> None:
        if self.viewport and (abs(dx) > 3 or abs(dy) > 3):
            self.viewport.ox, self.viewport.oy = self._drag_origin
            self.viewport.pan(dx, dy)
            self.queue_draw()

    def _on_pinch(self, gesture, scale) -> None:
        if not self.viewport:
            return
        ok, x, y = gesture.get_bounding_box_center()
        if ok:
            self.viewport.zoom_at(scale / self._zoom_origin, x, y)
            self._zoom_origin = scale
            self.queue_draw()

    # drawing ---------------------------------------------------------------
    def do_size_allocate(self, width, height, baseline) -> None:
        if self.viewport:
            self.viewport.resize(width, height)

    def _ensure_texture(self) -> None:
        if self._texture is not None or self.grid is None:
            return
        dark = Adw.StyleManager.get_default().get_dark()
        data = texture_rgba(self.grid, self.rooms, self.selected,
                            _DARK_BG if dark else _LIGHT_BG)
        self._texture = Gdk.MemoryTexture.new(
            self.grid.width, self.grid.height, Gdk.MemoryFormat.R8G8B8A8,
            GLib.Bytes.new(data), self.grid.width * 4)

    def do_snapshot(self, snapshot) -> None:
        if not (self.grid and self.viewport):
            return
        self._ensure_texture()
        vp = self.viewport
        rect = Graphene.Rect().init(vp.ox, vp.oy, self.grid.width * vp.scale,
                                    self.grid.height * vp.scale)
        snapshot.append_scaled_texture(self._texture, Gsk.ScalingFilter.NEAREST, rect)
        if self.grid.charger:
            self._dot(snapshot, *vp.to_widget(*self.grid.charger), 10, "#2ec27e", "#ffffff")
        self._labels(snapshot)

    def _dot(self, snapshot, x, y, r, fill, ring) -> None:
        for radius, color in ((r + 2.5, ring), (r, fill)):
            box = Graphene.Rect().init(x - radius, y - radius, radius * 2, radius * 2)
            snapshot.push_rounded_clip(Gsk.RoundedRect().init_from_rect(box, radius))
            snapshot.append_color(_rgba(color), box)
            snapshot.pop()

    def _labels(self, snapshot) -> None:
        dark = Adw.StyleManager.get_default().get_dark()
        accent = Adw.StyleManager.get_default().get_accent_color_rgba()
        for seg, (x, y) in self.label_points().items():
            room = next(r for r in self.rooms if r.id == seg)
            selected = seg in self.selected
            layout = self.create_pango_layout(None)
            area = f"\n<small>{room.area_m2:.1f} m²</small>" if room.area_m2 is not None else ""
            layout.set_markup(f"<b>{GLib.markup_escape_text(room.name)}</b>{area}", -1)
            layout.set_alignment(Pango.Alignment.CENTER)
            w, h = layout.get_pixel_size()
            box = Graphene.Rect().init(x - w / 2 - 10, y - h / 2 - 5, w + 20, h + 10)
            if selected:
                bg, fg = accent, _rgba("#ffffff")
            elif dark:
                bg, fg = _rgba("rgba(48,48,52,0.92)"), _rgba("#ffffff")
            else:
                bg, fg = _rgba("rgba(255,255,255,0.94)"), _rgba("rgba(0,0,0,0.8)")
            snapshot.push_rounded_clip(Gsk.RoundedRect().init_from_rect(box, 10))
            snapshot.append_color(bg, box)
            snapshot.pop()
            snapshot.save()
            snapshot.translate(Graphene.Point().init(x - w / 2, y - h / 2))
            snapshot.append_layout(layout, fg)
            snapshot.restore()
```

```python
            self.clean_button.set_sensitive(bool(n) and usable
                                            and snap.state not in ("cleaning", "returning"))
            start = self.action_buttons["start"]
            cleaning = snap.state == "cleaning"
            start.set_icon_name("media-playback-pause-symbolic" if cleaning
                                else "media-playback-start-symbolic")
            start.set_tooltip_text("Pause" if cleaning else "Start")
            for button in self.action_buttons.values():
                button.set_sensitive(usable)
        finally:
            self._updating = False

    def _update_rooms(self, rooms, selected) -> None:
        key = [(r.id, r.name, r.area_m2, r.color) for r in rooms]
        if key != getattr(self, "_rooms_key", None):
            self._rooms_key = key
            self.rooms_list.remove_all()
            self.checks = {}
            for room in rooms:
                row = Adw.ActionRow(title=GLib_escape(room.name))
                dot = Gtk.Box(width_request=12, height_request=12, valign=Gtk.Align.CENTER)
                dot.add_css_class("room-dot")
                provider = Gtk.CssProvider()
                provider.load_from_string(f".room-dot {{ background: {room.color}; "
                                          "border-radius: 4px; }}")
                dot.get_style_context().add_provider(provider,
                                                     Gtk.STYLE_PROVIDER_PRIORITY_APPLICATION)
                row.add_prefix(dot)
                if room.area_m2 is not None:
                    row.add_suffix(Gtk.Label(label=f"{room.area_m2:.1f} m²",
                                             css_classes=["dim-label"]))
                check = Gtk.CheckButton(valign=Gtk.Align.CENTER)
                check.connect("toggled", self._on_check, room.id)
                row.add_suffix(check)
                row.set_activatable_widget(check)
                self.checks[room.id] = check
                self.rooms_list.append(row)
        for seg, check in self.checks.items():
            if check.get_active() != (seg in selected):
                check.set_active(seg in selected)

    def _on_check(self, check, seg) -> None:
        if not self._updating:
            self.emit("toggle-room", seg, check.get_active())


def GLib_escape(text: str) -> str:  # noqa: N802 - ActionRow titles are markup
    from gi.repository import GLib

    return GLib.markup_escape_text(text)
```

```python
class _MicloudFilter(logging.Filter):
    """micloud logs through the root logger, sometimes with 2FA URLs; keep WARNING+ only."""

    def filter(self, record: logging.LogRecord) -> bool:
        return f"{os.sep}micloud{os.sep}" not in record.pathname or record.levelno >= 30


class ChippyApp(Adw.Application):
    __gsignals__ = {"state-changed": (GObject.SignalFlags.RUN_FIRST, None, ())}

    def __init__(self):
        super().__init__(application_id=APP_ID, flags=Gio.ApplicationFlags.DEFAULT_FLAGS)
        self.add_main_option("background", 0, GLib.OptionFlags.NONE, GLib.OptionArg.NONE,
                             "Start without a window", None)
        self.add_main_option("fake", 0, GLib.OptionFlags.NONE, GLib.OptionArg.NONE,
                             "Use a simulated robot (development)", None)
        self.add_main_option("test-state", 0, GLib.OptionFlags.NONE, GLib.OptionArg.FILENAME,
                             "Write UI state to this file (testing)", "PATH")
        self.fake = False
        self._start_hidden = False
        self._test_state_path: str | None = None
        self.state = "loading"
        self.controller: VacuumController | None = None
        self.credentials: credentials.Credentials | None = None
        self.profile = None
        self.runner = ThreadRunner()
        self._memory_keyring = None
        self._dbus = VacuumDBus(self.show_window)
        self.window = None

    # options and startup ---------------------------------------------------
    def do_handle_local_options(self, options) -> int:
        opts = options.end().unpack()
        self.fake = bool(opts.get("fake"))
        self._start_hidden = bool(opts.get("background"))
        path = opts.get("test-state")
        self._test_state_path = path.decode() if isinstance(path, bytes) else path
        if self.fake:
            # The fake must never touch the real config, cache or keyring.
            root = os.environ.get("CHIPPY_FAKE_HOME") or tempfile.mkdtemp(prefix="chippy-fake-")
            for var in ("XDG_CONFIG_HOME", "XDG_CACHE_HOME"):
                os.environ[var] = os.path.join(root, var.lower())
            self._memory_keyring = credentials.MemoryCollection()
            if os.environ.get("CHIPPY_FAKE_SIGNED_OUT") != "1":
                credentials.save(FAKE_CREDS, self._memory_keyring)
        return -1

    def do_dbus_register(self, connection, object_path) -> bool:
        Adw.Application.do_dbus_register(self, connection, object_path)
        self._dbus.register(connection, object_path)
        return True

    def do_dbus_unregister(self, connection, object_path) -> None:
        self._dbus.unregister()
        Adw.Application.do_dbus_unregister(self, connection, object_path)

    def do_startup(self) -> None:
        Adw.Application.do_startup(self)
        self.settings = Settings.load()
        if self.settings.background:
            self.hold()
        self._add_actions()
        self._load_credentials()
        if self._test_state_path:
            GLib.timeout_add(300, self._write_test_state)

    def do_activate(self) -> None:
        if self._start_hidden:
            self._start_hidden = False
            return
        self.show_window()

    def do_shutdown(self) -> None:
        if self.controller:
            self.controller.stop()
        self.runner.shutdown()
        Adw.Application.do_shutdown(self)

    def show_window(self) -> None:
        from .ui.window import MainWindow

        if self.window is None:
            self.window = MainWindow(self)
            self.window.connect("close-request", self._on_close)
        self.window.present()

    def _on_close(self, _window) -> bool:
        self.window = None
        return False  # destroy it; the app stays alive while held (background mode)

    # keyring and controller -----------------------------------------------
    def keyring(self):
        return self._memory_keyring or credentials.default_collection()

    def _set_state(self, state: str) -> None:
        self.state = state
        self.emit("state-changed")

    def _load_credentials(self) -> None:
        self._set_state("loading")
        import_legacy = not self.settings.signed_out

        def work():
            return credentials.load(self.keyring(), import_legacy=import_legacy)

        def done(creds, error):
            if isinstance(error, credentials.KeyringLocked):
                self._set_state("locked")
            elif error is not None:
                log.error("keyring failed: %s", error)
                self._set_state("locked")
            elif creds is None:
                self._set_state("signed-out")
            else:
                self._start_controller(creds)

        self.runner.run(work, done)

    def retry_keyring(self) -> None:
        self._load_credentials()

    def _start_controller(self, creds) -> None:
        try:
            profile = profile_for(creds.model)
        except UnsupportedModel:
            self._set_state("signed-out")
            return
        if self.controller:
            self.controller.stop()
        if self.fake:
            vacuum, fetch = FakeVacuum(profile), build_fake_payload
        else:
            vacuum = Vacuum.connect(creds.ip, creds.token, profile)
            cloud_map = CloudMap(creds)

            def fetch():
                return cloud_map.fetch_payload(vacuum)

        self.credentials, self.profile = creds, profile
        self.controller = VacuumController(vacuum, profile, RoomStore(), MapCache(), fetch)
        self.controller.connect("notify-user", self._notify)
        self._dbus.attach(self.controller)
        self._set_state("ready")
        self.controller.start()

    def sign_in_with(self, creds) -> None:
        def work():
            credentials.save(creds, self.keyring())

        def done(_r, error):
            if error is not None:
                self.window and self.window.toast(f"Couldn't save to the keyring: {error}")
                return
            self.settings.signed_out = False
            self.settings.save()
            self._start_controller(creds)

        self.runner.run(work, done)

    def sign_out(self) -> None:
        if self.controller:
            self.controller.stop()
        self.controller = None
        self._dbus.attach(None)
        self.settings.signed_out = True
        self.settings.save()
        MapCache().clear()
        self.runner.run(lambda: credentials.delete(self.keyring()), lambda *_a: None)
        self._set_state("signed-out")

    def cloud_factory(self, username: str, password: str):

        self.window and self.window.toast("Preferences come in the next build")
```

```python
"""Sign in to Xiaomi: password, captcha, email code, pick the vacuum."""

from collections.abc import Callable

from micloud.micloudexception import MiCloudAccessDenied

from ..core.accounts import credentials_for, discover_vacuums
from ..core.cloud import CaptchaRequired, TwoFactorRequired

ATTEMPTS = 3


class LoginFlow:
    """GTK-free sign-in state machine; `on_page(name, data)` drives the UI."""

    def __init__(self, cloud_factory, runner, on_page: Callable[[str, dict], None]):
        self._factory, self._runner, self._on_page = cloud_factory, runner, on_page
        self._cloud = None
        self._username = self._password = ""
        self._captcha_tries = self._code_tries = 0
        self._two_factor_url = ""

    def _error(self, page: str, message: str) -> None:
        self._on_page("error", {"page": page, "message": message})

    def sign_in(self, username: str, password: str) -> None:
        self._username, self._password = username.strip(), password
        self._cloud = self._factory(self._username, password)
        self._captcha_tries = self._code_tries = 0
        self._login()

    def _login(self) -> None:
        self._runner.run(self._cloud.login, self._after_login)

    def _after_login(self, ok, error) -> None:
        if isinstance(error, CaptchaRequired):
            url = error.url
            self._runner.run(lambda: self._cloud.fetch_captcha(url), self._show_captcha)
        elif isinstance(error, TwoFactorRequired):
            self._two_factor_url = error.url
            self._runner.run(lambda: self._cloud.send_email_code(self._two_factor_url),
                             lambda _r, err: self._error("account", str(err)) if err
                             else self._on_page("code", {}))
        elif error is not None:
            self._error("account", str(error))
        elif not ok:
            self._error("account", "Xiaomi rejected the email or password.")
        else:
            self._discover()

    def _show_captcha(self, image, error) -> None:
        if error is not None:
            self._error("account", f"Couldn't load the captcha: {error}")
        else:
            self._on_page("captcha", {"image": image})

    def submit_captcha(self, code: str) -> None:
        self._captcha_tries += 1
        self._cloud.captcha_code = code.strip()
        self._login_after_captcha()

    def _login_after_captcha(self) -> None:
        def after(ok, error):
            if isinstance(error, CaptchaRequired) and self._captcha_tries >= ATTEMPTS:
                self._error("captcha", "Xiaomi kept asking for a captcha; try again later.")
            else:
                self._after_login(ok, error)

        self._runner.run(self._cloud.login, after)

    def submit_code(self, code: str) -> None:
        self._code_tries += 1

        def after(_r, error):
            if isinstance(error, MiCloudAccessDenied):
                if self._code_tries >= ATTEMPTS:
                    self._error("code", f"{error}. Start over to get a new code.")
                else:
                    self._error("code", str(error))
            elif error is not None:
                self._error("code", str(error))
            else:
                self._discover()

        self._runner.run(lambda: self._cloud.verify_email_code(code.strip()), after)

    def resend_code(self) -> None:
        self._code_tries = 0
        self._runner.run(lambda: self._cloud.send_email_code(self._two_factor_url),
                         lambda _r, err: self._error("code", str(err)) if err else None)

    def _discover(self) -> None:
        def after(found, error):
            if error is not None:
                self._error("account", str(error))
            elif not any(v.supported for v in found):
                self._error("account", "No Dreame vacuum on this Xiaomi account.")
            else:
                self._on_page("devices", {"vacuums": found})

        self._runner.run(lambda: discover_vacuums(self._cloud), after)

    def choose(self, vacuum) -> None:
        creds = credentials_for(vacuum, self._username, self._password,
                                self._cloud.session_state())
        self._on_page("done", {"credentials": creds})
```
